#  JobPilot

JobPilot is a full-stack **MERN** application that helps users manage and track their job applications in one place. Users can create, edit, delete, search, filter, sort, and organize job applications while securely storing resumes.

---

##  Features

*  User Authentication (JWT)
*  Add Job Applications
*  Edit Existing Jobs
*  Delete Jobs
*  Search Jobs
*  Filter by Job Type
*  Resume Upload
*  Favourite Jobs
*  Dashboard Statistics
*  Pagination
*  Sorting
*  Responsive Design

---

##  Environment Variables

Create a `.env` file inside the `server` folder.

env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
